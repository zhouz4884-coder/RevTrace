# Reproduction and evidence identity

Each original run keeps its actual frozen SOURCE/commit, config/environment,
raw8TBpath and terminal gate. The public archive commit is not a substitute
for any execution commit. Git bundles preserve the full executable histories;
tar snapshots and file manifests preserve byte identity, including failures.

Models, original audio, environments and large scratch remain on the named8TB
disk. Compressed bounded scientific records are byte-indexed for review.
Absolute raw paths in frozen records are original locators, not portable
defaults: a reproduction on another host requires an explicit audited path
mapping and the same content-hashed assets. Do not edit the old frozen records
in place or claim a source-identity check alone proves a GPU run.

`inputs/PAID_OPERATOR_CASES.json` in the terminal update is the complete two-case
paid-input definition (original peers/order, old/new snapshots and reference
receipts), SHA256
`743b64804d6ffba7c0e94fc5c6f69a3be962e48fe3b4d717186713c504c338da`.
The shared wait prior bank has SHA256
`a333ef9f8b164a8ca259e39f3414231fea57c85ff50831085765e4845306bf03`.
It contains393row observations, not393independent physical batches.

For local source inspection use the checked current pointer or explicit
`preflight.py --source <clean extraction> --manifest <SOURCE.json>` after
importing the bundle's actual full commit. A different clone must supply its
own clean source paths rather than reuse this machine's CURRENT.json.
Actual executable argv/config are recorded in each FREEZE/COMMAND file.

Selected nonsecret orchestration recipes are retained in the terminal update.
They use an external authorized SSH helper whose credentials are intentionally
not included. These recipe files reflect their final bounded CLI, whereas
per-run frozen argv/source/manifest define each earlier execution. Neither
recipe defaults nor a newer archive HEAD relabel an old run.

The original CPU checker mistakes have explicit errata and corrected sources.
Use paid-context auditv2and waiting-closure auditv2, not their earlier failed
or incomplete interpretations. The underlying immutable GPU records were
not re-generated to make a comparison favourable.
