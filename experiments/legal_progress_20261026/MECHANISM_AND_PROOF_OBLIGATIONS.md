# Mechanisms and conditional guarantees

## S: complete legal-progress query

For already host-verified, Consumer-registered and currently permitted
provisional results E_registered(t), select
argmax(F(p), original-publication-order, original-job-ID) among p compatible with
the actual applied root. The selected text is the whole original hypothesis,
never a certified suffix. Re-run the same query on a new canonical root AND on
an incompatible newly arrived private result. The CURRENT triggering publication
is authorized by the original kernel; the selected older job keeps its original
identity, audio, epoch and output. No new model execution is asserted. The
implemented Consumer selector does NOT establish maximality over arbitrary
unpublished/queued host results. That larger E_host(t) requires a new registration/
reauthorization interface. The separate raw registry upper-bound audit found12
apparent cuts, all invalid after actual generation retirement; none justifies
that extra interface in this bank.

Safety follows conditionally from: host trusted Render and immutable job/result;
FIFO owner/epoch/contract/mode fences; exact original compatibility including
ancestor multiplicity; final original kernel apply-request/view-applied gate;
no transition grants private canonical-write permission. The CPU fixture follows
actual dispatch/return/Render/Input WAL/Canonical WAL/publication/kernel/Consumer
and does not assign P hashes arbitrarily. Its model is scripted, not neural.

Payload deletion requires future support set inclusion and a no-smaller frontier
plus coupled permission lifetime and immutable proof uniqueness. If i dominates
j under those premises, any future root accepting j also accepts i, with F(i)
>=F(j); removing j's payload cannot reduce the maximum. Keep ancestor edges and
multiplicity witnesses even when text is discarded. A new individually revoked
i or newly ambiguous ancestor invalidates this proof. Defaults therefore do NOT
perform semantic dominance deletion with individual revocation/unsealed graphs.
Typed CERTIFIED-ONLY/RECOVERY withdrawal permanently retires the known tips;
NORMAL does not restore their permission. A later canonical incompatibility by
itself is not such a revocation. Recovery creates a new stream/epoch and registry.

The final compiled selector additionally filters the stricter unchanged generic
kernel J-graph relation. A pure CPU cross-branch ambiguity control shows native
branch-local compatibility can accept a tip that the core's all-parent
multiplicity check rejects. Select the best JOINTLY admissible tip rather than
crashing on that tip. With this extra kernel predicate, semantic payload deletion
is conservatively disabled until joint future support sets are proved. The
existing14 raw witnesses already pass the independent core check; this hardening
does not fabricate a new GPU opportunity or change any measured runtime.

An ordinary per-root best-version index satisfies the same objective. If it
matches scan/retention there is no independently novel indexing result. The
unbounded FIFO, durable transaction lookup and audit archive remain outside a
provisional-payload space claim. Ordinary event-local COW is offered to every
baseline; its map copies are still O(history), not bounded-memory or O(1).

## X: current-input verification and continuation

Let L be actual processed target prompt width, d its untrusted draft, and a the
first mismatch with trusted target predictions. Only KV freshly computed from
THIS target input is retained. Crop to L+a (exclude rejected position), append
the trusted bonus prediction at a if not already terminal, and generate residual
tokens under the remaining declared budget. Full accepted EOS terminates without
bonus; a no-EOS output is complete only at the exact budget. Never accept old
context KV, approximate state equality, token-only provenance, or a stale target.

Under exact deterministic causal target semantics, the accepted draft prefix
equals target generation by induction; after cropping, the retained target KV
is precisely the state of that prefix; trusted bonus/residual extend that same
history. Floating point/GEMM layout can violate the mathematical premise: test
full Z, Stop, Phi and text against native same-input repeated generation. These
are bounded numerical controls, not a global bitwise theorem.

The algorithm is standard speculative prefix verification (ICML2023) and has a
close native VoiceAgent implementation. Our HF/eager implementation is independently
written and credited, not unchanged native FlashAttention performance. No upstream
unlicensed source is redistributed. Shared prefix wins are not exclusive C2.

## M: independent source validity and output authority

OCC validates the actual document versions read. It does not establish that the
returned content was selected by a trusted current-context operation. The new
application uses separate actual proposal/authority pipes; the controlled fault
can replace only a proposal payload and its self-checksum. Host pipe ownership
is the origin boundary, not protection against hostile trusted-host Python.
Authority selection binds actual current processed input, runtime, effective
logits processors, all tokens/Stop and stable-ID state. Protected installation
uses the same current-readset transaction and real SQLite FULL WAL; RevTrace
also passes the existing complete admission/application kernel. The read-only
answer role cannot install memory.

Generation has a provider repetition penalty1.1. Raw teacher-forced argmax is NOT
the actual selection predicate. v1 self-check correctly failed; v2 applies the
same HF processor to the actual prefix at every scored position without changing
the generator or any strong baseline. Unknown configured processors fail closed.
An Authority can still select a factually wrong value: provenance is not truth.
Missing current memory is explicit abstention/unfulfilled service, not success.
Cross-store serialization is the adapter's explicit assumption; this study is
not a theorem about arbitrary concurrent writers or native LangGraph security.
