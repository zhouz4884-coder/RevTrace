## What ran

- S: existing CK5/N5 actual GPU-log opportunity scans; actual FIFO CPU replay;
  full native protocol CPU counterexample; safe selection/retention controls.
- X:24 pilot checks and32 paired target tuples×4 methods with paid fresh producer;
  16 actual full-audio service runs;48 separately paid actual-parent target controls.
- M:320 actual actor/SQLite applications plus64 content-only fault controls;
  old24 attribution and16 truthful-memory calls on the original responder.
- Final frozen-source32 CPU tests; all raw-archive files independently hashed.

Evidence tiers are explicit: CPU scripted model, retrospective old-real-GPU
opportunity, conditional-state GPU operator, actual low-concurrency development
service, controlled non-ASR application fault and separate diagnostic oracle.
Do not merge them into one natural rate or service-speedup claim.

## Important distinctions

- The native canonical/private two-register baseline is an alias of the current
  two-lane selection semantics, not another independent competing algorithm.
- S maximizes jointly legal Consumer-registered previews. It does not give old
  publications new versions, private output state-write permission, or a global
  unpublished-host-result maximum. Generic-kernel ambiguity is filtered too.
- KV is NEW under the actual current target input. Standard gets the SAME
  prefix executor. This is an independently written credited HF/eager adaptation,
  not unchanged VoiceAgent native-engine performance or exclusive decoding novelty.
- The legacy scheduler config tag `verification_policy=canonical_generate` is
  kept for wrapper compatibility; `prefix_executor_mode` and the authority runtime
  explicitly declare the ACTUAL fresh/verify/fallback/prefix operation.
- M OCC correctly validates versions. Without trusted selection it can still
  admit a coherent low-trust value. Full Standard+Strict and RevTrace match.
  Correct memory does not guarantee the next answer, and abstention is not fresh
  state. The64 extra content-only controls remove a formatting confound without
  replacing the original320 results.
- Normal M costs use the declared sequential tool-return API, not an optimal
  overlapping regeneration scheduler. X service has nonblocking ready-only seeds.
- Prepared/failed audit revisions and unexecuted service-v1 source are identified;
  no failure is relabeled as a successful GPU experiment. CPU-only token encode
  messages are not GPU calls; diagnostic oracle work is not free serving work.
