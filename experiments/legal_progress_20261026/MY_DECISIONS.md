# Independent reasoning and scope decisions

1. Maximum legal progress must be re-evaluated after BOTH a canonical update
   and an incompatible new private display. Only changing canonical handling
   does not establish F* at every actual application event.
2. A canonical incompatibility is not automatically an irreversible revocation.
   Original owner/epoch, current mode and explicit revocation remain required.
   The first raw scan uses a conservative mode-withdrawal floor. Before a final
   zero-opportunity conclusion, independently check the permissive native-core
   interpretation too; do not hide opportunities with an invented TTL.
3. Dominance needs more than root-set inclusion: future individual revocation
   or newly ambiguous ancestry can resurrect a discarded candidate's value.
   Therefore the prototype defaults to NO dominance deletion with individual
   revocation/unsealed graph growth. Owner-mode-only revocation and a validated
   monotone one-node-per-branch/window publication contract are explicit optional
   conditions, available identically to every baseline. Old-epoch views reset.
4. Candidate payloads and proof edges are different. Dropping a tip's text must
   not remove an ancestor or a multiplicity witness and turn an ambiguous path
   into an accepted one. Canonical transaction lookup/slow FIFO/audit archive
   are outside a provisional-payload-only space claim.
5. A strong ordinary reverse-query index can keep the best candidate per future
   legal root key. Under immutable supports and coupled permission lifetimes,
   the union of these winners can be at least as compact as pairwise dominance
   (collective coverage may dominate a tip without one dominating successor).
   Include this as a serious comparator; do not call familiar indexing new.
6. The full CPU regression fixture uses the actual scheduler, native rollback5
   renderer (a declared character tokenizer/parser), real Input/Canonical WAL,
   kernel authorization and actual FIFO Consumer thread. Its scripted current-
   input outputs make C2.P=A12.P legal under the adapter but are NOT neural
   evidence or measured6/12/14/16-second performance. Real prevalence remains
   subject to the raw scan and any legal actual-model controls.
7. CK5 first raw cut:136 attempts,2948 canonical updates, zero consumer-known
   or host-published upper-bound improvements. Original actual views replay
   exactly. This is not the whole historical pool or a population prevalence.
8. Prefix KV is newly computed under current target audio and conditioning.
   Old-context cache cannot be retained. Strict fresh-target equivalence, a
   declared speculative-decoder contract, Stop completeness and source identity
   are separate guarantees. Probe cache positions, first mismatch, EOS full
   accept, budget exhaustion, audio feature recomputation and finite-precision
   layout effects; preserve every mismatch and every paid call.
9. VoiceAgent upstream8b5a0f9cc2f0cdaed692c876b4c682d54635dc0c has the native
   transcribe_with_draft mechanism. It has no root license file in the inspected
   tree and requires missing FlashAttention. Keep inspection private and do not
   redistribute it. An independently implemented HF/eager adaptation is NOT an
   unchanged native-engine reproduction and must be labeled explicitly.
10. ER1 old56 development calls and failed7B2 calls remain negative evidence.
    Its16 FP32 ideal-memory calls are an operator control, not actual application
    quality. Use saved common-upstream outputs/repeated inputs for diagnosis;
    final orthogonal results still require actual proposal, selection, store
    installation, subsequent input and new model output. No fault in trusted
    Authority may be relabeled as a low-trust proposal attack.
11. There is a useful deadline bound: with uniform fine2s release and D=2s,
    observing a STRICTLY newer full-window tip Fi>=Fj+2s implies the time is
    already >=Fj+2s (plus the newer computation). Resurrecting Fj then cannot
    newly meet Fj's FIRST-display deadline. A previously displayed Fj also
    already has its original first-view credit. Thus do not sell the supplied
    A14/B16 example as a2s Goodput win. It may improve sustained legal coverage,
    retraction duration or a different SLO; fractional EOF/bursty release and
    never-published quarantined results need separate analysis.
12. The supplied E_t includes already HOST-verified rows, not only published
    Consumer nodes. Complete the audit with immutable unpublished/retired rows
    as a separate reauthorization upper bound, and with cuts at result
    availability as well as canonical updates. Current Consumer-only code
    cannot claim such a registry already exists. No old revision is relabeled;
    any real integration must select via the current trigger/kernel and charge
    actual registration/enqueue/application. Exclude future completion and
    context-forged rows; describe post-hoc 'would be retired' labels as audit,
    not algorithm inputs.
13. A frozen candidate-transformation rule is needed for prefix reuse. Current
    target conditioning prefix and earlier complete projected transcript are
    different units from raw incremental Z. Choose a candidate by ready time
    first, then deterministically remove an EXACT matching current conditioning
    prefix/encode its suffix. Do not inspect future target match lengths to pick
    a seed. Retired seeds can only propose tokens for NEW correct-input trusted
    computation, never bring old KV or install authority.
14. When no shared FlashAttention native environment is available, implement an
    explicitly credited independent HF/eager prefix-accept/crop/bonus/residual
    baseline. Native-source inspection is not a native reproduction. Both
    baseline and RevTrace use the SAME continuation executor; account target
    encoder/verification/fallback, paid proposer and diagnostic oracles.
15. v1 M self-check failed on one development source despite deterministic
    repeated generation. Actual GenerationConfig revealed repetition_penalty1.1:
    raw teacher-forced argmax is not the true selection operation. Do not disable
    the penalty or change the generator to make verification pass. v2 verifies
    the same actual prefix with the original HF processor. Original v1 failure
    and actual wrong Authority destination on that source remain evidence.
16. The v1 independent quarantine audit had a real field-name error: retirement
    emits `generation` AFTER increment, not `branch_generation`. All12 putatively
    available unpublished cuts were explicitly retired generations. v2 rejects
    all12. Keep v1 and identify its counts as invalid, not new opportunities.
17. N5 yields14 real already-published historical improvements (11+1+2 in three
    attempts); every one has zero newly achievable FIRST2s deadline coverage.
    The actual FIFO CPU re-application and original kernel accept them. Ordinary
    multiversion indexing matches full scan and candidate retention, with no
    observed uniquely better service or query cost. This is a selectable-view
    completeness repair, NOT yet an independent fast new selection algorithm.
18. X32 exact conditional-state operator controls passed. Paid producer+target
    compute ratios prefix/Fresh are source-cluster means0.853(rho1),0.547(rho3).
    These are not streaming speedups. Actual service must re-create its own
    canonical histories, pay both GPUs, include WAL/Consumer and count all offered
    audio. Prefix baseline and RevTrace share the SAME standard algorithm.
