# Selected native-record counters

Pure standard-library aggregation of the records actually selected into durable
Canonical facts. The starting_tokens-derived native_model_evaluated marker is
reported as a marker, with strict true/false/unknown counts. It is not a decoder
or CUDA kernel forward probe. Correction payload presence, returned IDs, and
selected model_seconds are separate observations. No total paid-work or novel
correct-transcription claim follows. Warmup, discarded calls and killed work
require separate evidence and are not silently included or assigned zero cost.
