# E1 frozen fixed-state protocol, 2026-10-18

24 contexts = every one of the existing 12 constructed sources at parent
frontiers 12 and 18 seconds. They are not 24 independent audio sources or
new speakers. Same-language context partners rotate deterministically, with
no selection using confidence, labels or model outcomes.

The GPU worker substitutes the actual prompt tokens **before decoding and
model execution**, retaining the legitimate job metadata and audio. Private
worker and authority are separate processes, devices and model instances.
Actual-context digests are recorded as observer instrumentation, not trusted
remote-execution attestation. Fault injection is explicitly enabled only for
this probe SDK. The independently executed correct-context authority selects
the protected output.

Matched phases: clean proposer, F2 wrong proposer context, actual-context
teacher-forced re-score, correct-context re-score, clean authority plus
same-input repeat, F5 wrong authority context, and fixed-future protected /
unprotected / protected-repeat continuations. Threshold .05 retains the
existing margin-inspired heuristic's rule. Teacher-forced scores and their
cost are separate controls, not the native published margin algorithm.

Report raw wrong-context projection and a cheap reconstruction under the
declared correct parent separately. Reconstruction may repair a field while
the actual generated continuation remains different; do not assume that it
fails, or that every F2 context changes the output. F1 stale-epoch fencing
is a CPU replay using the real job/results; it is not another GPU trial.

The initial parent contents are frozen trusted state fixtures derived from
the historical committed trace, declared as initial probe state under the
new experiment contract. These are fixed-state GPU fault probes, not a live
arrival benchmark or a demonstration of cross-contract production migration.

All future audio is fixed, ending at each full source's exact endpoint.
Compare new generated output separately from copied prefixes and full-reference
WER/CER. Repeated context exposures stay clustered by source. Keep zero
propagation and oracle-repeat disagreement. F5 deliberately violates the
trusted-authority assumption; accepted corrupted authority content is a
negative control, not a guarantee failure within the fault model.

No new live-serving throughput, natural SDC rate, hardware-fault independence,
or general semantic completeness claim follows from this campaign.
