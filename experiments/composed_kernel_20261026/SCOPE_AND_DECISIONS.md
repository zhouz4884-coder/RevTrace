## What may count as a contribution
- C1: Preserve trusted selection/Parent/frontier and provenance binding. Do not
  recast coherent synthetic private corruption as naturally occurring errors.
- C2: A composition argument and the actually executed C/D/V/I/J kernel can
  strengthen the protocol result. An API extraction alone is not a new method.
  Finite enumeration characterizes only its declared bound; independent
  traversal of the same spec is not independent semantics or a full stack proof.
- C3: Early restoration must be measured on the complete original fault domain.
  Separating durable fact availability from executor readiness is a shared
  safe service improvement, not an exclusive gain over complete Standard.

## Fair counterfactuals
Formal normal and first-dispatch-after-14s recovery have three arms per model,
method and repeat: legacy startup without kernel; early startup without kernel;
early startup with kernel. This separates startup repair from kernel overhead.
Both RevTrace and complete Standard use the same workers, limits, input,
Row-complete SDK, actual Consumer, WAL and original clocks. Fine-grid boundary
probes likewise give complete Standard the identical fine grid.

The validation sources are a frozen metadata-selected N5 pool, reused here;
they are not freshly unseen merely because this runtime is new. Row count,
session count, unique source count and repeats must be reported separately.
Small repeat counts do not support a universal RTO/P99 guarantee.

## No premature success

illegal late-result behavior, initialization/epoch/identity/lease CPU controls,
actual feedback consumption in both models, all completed and failed work
accounting, source hashes, immutable raw index and independent recount.

repeat and legal oracle controls. Do not alter a strong baseline to win.
