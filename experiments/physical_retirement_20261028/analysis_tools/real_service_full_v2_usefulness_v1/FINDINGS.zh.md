配对分解：covered 的 ahead 原文一致信用增加 **35.385 / 33.255 秒**，但首次即认证信用减少 **20 / 16 秒**；合并后才是 **+15.385 / +17.255 秒，即 +6.15 / +6.90 个百分点**。这证明的是总体净支持量保留，未依据这四个摘要文件声称每一个 gained frontier 都原文一致。

**文本修订负担没有被零音频回撤掩盖。** 每个 F2 cell 都有 **8 个**原文不同的首次提前视图，覆盖 **16.000 秒**音频，且这 16 秒均获双期限信用；规范化后仍有 **7 个、14.000 秒**不同。clean 各 cell 为 **1 个、2.000 秒**原文不同，规范化后为零。所有 cell 的 same-F 未匹配音频均为 **0 秒**；这组 rho=1 结果不能替代 rho=3 非共同边界的未匹配报告。规范化只移除格式差异，不是语义正确认证。

**parent/watchdog 的取舍仍在，且本次没有“更多坏 preview 数”的证据。** F2 各策略不同文本的次数和音频秒完全相同，故支持端点的排序没有因扣除修订而反转：parent 相对 covered 为 **+6.680 / −5.955 秒**；watchdog 为 **−0.455 / −5.720 秒**，不存在 parent 在两次均更优。不同文本的累积 session-wall 暴露仍有差别：covered **5.289 / 5.594 秒**，parent **5.748 / 6.154 秒**，watchdog **6.269 / 6.804 秒**。这是并发会话暴露之和，不能当额外音频秒、独立样本或错误率。

实际 Canonical 安装相对提前可见的音频加权平均 lead：row_complete **321 / 421 ms**、covered **388 / 435 ms**、parent **396 / 436 ms**、watchdog **419 / 444 ms**；实际 Consumer 认证观察再晚约 **12–14 ms**。各 cell 的首次提前音频均确实早于选中安装，没有把“已经选中、仅 Consumer 尚未观察”的传输时差冒充计算提前。这些均为所有首次提前音频的均值，不是仅一致文本的均值。

**决定：保留 covered 的有限服务价值依据，继续按冻结 H3 检验组合贡献。** 这里的支持是后见同 F Canonical 支持，不是 groundtruth、在线验证或最终识别正确；最终 WER 在全部 cell 仍单列为 **2.0378457%**。这仍是旧开发来源、受控 F2／clean 的两次重复，不能宣称自然故障普遍性、独立来源优势、确定性保证或已完成 DSN 组合创新。
