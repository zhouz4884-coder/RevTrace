# Indexed evidence integration, frozen before CPU execution

No new GPU generation, no paper edits, no changed selection/admission rules.
Source identity, index byte hashes, environment and output paths are frozen
before each read-only analysis. Failed versions remain in new numbered outputs.

## Paid work and critical paths

Read all six terminal v10 c16 staggered policy cells, not just a winner.
Count GPU0/GPU1 owner leases from trusted dispatch to batch-drained receipts;
separately count physical worker spans and synchronized model-call wall.
Early row availability never releases a physical worker. Host/transport and
model intervals must partition each paid lease without overlap or missing time.
Partition entire batches by zero/some/all obsolete rows, never invent a per-row
cancellable compute share. Covered-but-unissued and expired-but-unissued jobs
are disjoint and are not measured reclaimed GPU time.

Reconstruct every Authority audio-frontier latency from real release, legal
parent install, input ACK, enqueue, worker start, host receipt, WAL install and
actual Consumer application. Queue/busy overlap is a union, not an additive
list of causes. Per-frontier paths are not additive GPU physical work.
Free-run input and batching differences are descriptive observations, not
isolated causal cost shares. The fixed-layout paid old/new operators supply
the separately scoped causal evidence; no illegal old input is live-admitted.

## Native actual-input and writeback

Include all 20 clean native cells, both model studies, two task families,
all three offered cycles including unfulfilled cycles (60 denominators).
Reconstruct recorded model messages/input IDs, durable prior receipt, selected
output, independent task judgment and subsequent write. Recount the local
objective using only frozen source/request; this analysis never calls a model
or admission code and never supplies an answer to a model.

Compare to the full Standard direct reference at each source/request, but
label different precision/selection contracts: this is not a feedback-only
intervention. Distinguish present invalid output, unauthorized provenance,
actual future consumption, and task loss relative to a successful reference.
Zero successful references cannot establish protection of task quality.
Keep native schema/budget/numerical failures and all NO-GO decisions visible.

## Acceptance

Every consumed file must match an archived raw-index size and SHA256. Any
missing field, impossible clock order, unmatched task score or incomplete
paid lease is a preserved analysis failure, not a fabricated zero or repaired
old measurement. Successful output contains JSON, per-event CSV, input hash
index, explicit scope and GO/NO-GO. This is CPU reconstruction of real prior
GPU records, not new online GPU evidence or new independent task observations.
