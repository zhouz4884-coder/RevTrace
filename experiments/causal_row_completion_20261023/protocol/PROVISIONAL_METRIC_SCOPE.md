# What the Display/quality metrics certify

The frozen Consumer's `valid_visible_frontier` is a bound-text and declared
version/Exact-P compatibility criterion. It is not independent certification
that every FP16 Proposer executed the expected feedback or that its temporary
text is accurate. In the deliberate F2 experiment,the untrusted Proposer consumes
an overridden context while returned fields are normalized to the declared
parent. This is a field-consistent bad-candidate construction,not generation
under that correct parent. Actual execution context and generated Z remain logged.

Display Permission intentionally permits provisional hypotheses without giving
them Canonical state-write permission. Authority execution is independently
checked against the actual declared target/context. Final WER/CER in the formal
tables is measured on full-source **certified Canonical text**,not per-frontier
provisional accuracy. Visible/certified rollback and erased text are separate.
A higher legal-display Goodput does not establish better temporary recognition
quality or that an injected private fault was never visible. No metric or baseline
is silently changed to hide that distinction.

The F2 dose audit additionally distinguishes explicit changed feedback on a Job,
actual processed-ID change,and possible physical co-batch shape exposure. A
padding/width counterfactual is CPU input reconstruction,not proof that another
row's neural output changed. The old excess-fallback count cannot by itself
separate private-ancestry continuation from batch-shape/numerical effects.

`cohort8` is the original two8-source cohorts,32s apart with0.25s intra-cohort
stagger. It is not an automatically guaranteed steady-state concurrency of8;
processing tails may overlap. Both cohorts retain the same16distinct sources.
The metadata field `headers_scanned=17022` in source selection is an unchanged
historical counter of candidate FLAC paths traversed before duplicate/exclusion
filters,not17,022distinct subjects or necessarily17,022header reads.
