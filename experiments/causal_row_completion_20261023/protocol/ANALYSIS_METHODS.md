## Causal versus descriptive evidence

Old ancestry,logical parent inequality,actual input realization,selection rejection
and observable previous-fallback signals are distinct. A primary reason hierarchy
is a reporting partition,not an assertion of one unique cause. Accepted descendants
are explicit counterexamples to a deterministic rejection cascade.

An actual incompatible private publication can be identified by replaying the
unchanged Consumer's exact compatibility test and matching actual Consumer records.
That is a witnessed unavailable display path,not proof that all of its delay is
removable. A measured model phase across a deadline is actual occupancy,not proof
that the target row had or had not already reached EOS. Descriptive deadline flags
can overlap and must never be summed as percentages of a single causal pie.

The120+30 matrix estimates shared Executor return benefits and interaction with
existing policies. Static function audit confirms that the five original readiness,
reconciliation,dispatch and commit functions remain AST-identical;Job construction
adds one actual contract_epoch binding field. Receive/drain control changes and
the per-row paid-fallback proof bridge are explicit. This is not a proof that all
possible completion-aware algorithms are equivalent. It does mean that this SDK
does not contain a distinct new dispatch/rebase/Rescue rule to which an independent
algorithm gain can automatically be credited. The original C2 contribution is
not invalidated by this narrower statement about the present increment.

under the correct parent. Endpoint full-source WER/CER is measured. Intermediate
