# Actual lineage opportunity: frozen two-axis contract

V2 preserves the completed V1 source/result. It separates the registered job
or ready record from retention-policy selection eligibility. An immutable
Ready-only fence takes effect at its recorded canonical install boundary,
even though the physical model/record may remain until a later terminal. A
successful survivor requires both a retained record and no permanent policy
fence through own-input confirmation, followed by actual same-job selection.
"Policy selection allowed" means not disqualified by that retention policy;
it does not grant AU before the complete own input is confirmed. An emitted
fence without an exact onset is unknown at an earlier boundary, never assumed
absent. The fence's explicit order is bound to an actual same-source install.

This is a CPU read-only recount, not another neural execution. First run covers
all 80 completed NN1145 native cells (all five policies, all eight speakers,
both repeats). The forthcoming natural MD68 bank is explicitly pending: 6*N,
at most 24 cells, determined by the unchanged metadata-selected actual N. It is
not silently counted as zero, and no speaker is chosen from observed effects.
Later the same parser can consume a separately frozen complete-bank config.

An actual ancestor refutation requires a full frozen dependency cut at F less
than the job's own start frontier, and an actual installed original fact at
that same F with a different complete JSON encoding. Birth-root/version change,
matching/different text, a durable append alone and eventual reference states
do not qualify. Full state includes every declared native field. Input keys
also bind actual original PCM16-to-float32 added-audio bytes, target, EOS and
NN1145 identity. Each frozen dependency edge needs a prior physical forecast or
admitted original-full-result witness. Dispatch birth roots are replayed from
actual earlier installations. Common Owner dispatch/receipt/install sequence
numbers must be complete, unique and ordered; Owner namespaces are separate.

Axis 1 reports every dispatched job, including those never promoted. It records
whether a real ancestor was refuted after dispatch; whether that original job
or its admitted ready result was still logically owned; whether a later actual
canonical installation confirmed its complete own start; and whether that same
original job was eventually selected/installed. Abandonment, discard, fencing
and lifecycle termination cannot be relabelled as survival. An eventual input
match after retirement or reissue is retained as a separate non-survivor
diagnostic. Missing own-frontier evidence is censored/unknown, not refutation.
Physical completion with an Owner-admitted buffered result is owned-ready,
not logical retirement. Actual model-active is labelled only if native-model
evaluation is true and recorded worker model begin/end wrap the queried perf
instant. Owner-inflight alone never means model-active; missing stage clocks
remain unknown. These intervals are host model-phase wall time, not GPU kernel
time or counterfactual savings.

Axis 2 independently records complete-input confirmation and a change from the
same job's typed early forecast to its complete original C/U result. It can
overlap axis 1; it does not substitute for ancestral reconvergence. Missing
forecast/full-result evidence remains unknown. Final text equality alone is
never a complete-state witness.

All cell configs, closed original-task/job/Consumer gates, raw WAL frames,
dispatches, physical worker results, policy audits, actual install events,
Supervisor recovery roots and original WAVs are bound in a full input hash
manifest. WAL scanning imports only the separately verified pure parser from
the unchanged 67-file NN1145 source. Neural modules are forbidden and CUDA
visibility is empty. Every run writes CONFIG, ENVIRONMENT, RUN_RECORD, controls,
per-cell results, SUMMARY, input manifest and gate on the 8TB disk. A positive
case is never a pass requirement. Zero, negative and unknown outcomes remain.

Constructive controls cover a three-frontier/four-call convergence, live and
owned-ready survival, birth-root-only change, one non-text field mismatch,
eventual match after retirement, wrong chronology, missing neural clocks,
wrong added-audio key, a retained but policy-fenced record, and the independent
overlapping forecast-change axis.
Positive cases export full original frozen input, original messages and
actual facts only to the raw 8TB audit output. Bounded reporting may export
metadata/hashes; audio-bearing states are not required in a public summary.
No alternate schedule, end-to-end policy speedup or saved GPU-seconds is
identified by this recount. No NN, campaign driver, prior formal analysis or
manuscript is modified.
