# Final4f archived deadline sensitivity

Independent CPU source; **not executed during development**. Root freezes the complete source, input config, environment, raw paths and experiment record before formal controls/analysis. No model, old raw reader, text normalization, runtime/CURRENT or paper modification.

Minimal input index: original `PAIRED32_V2_RESULTS/{SUMMARY,GATE,CONFIG}.json`, `RESIDENT4_V2_RESULTS/{SUMMARY,GATE,CONFIG}.json`, and the original `dsn_streamcorrect_independent_20261029/SOURCE_RECEIPT_v1.json` (frozenSHA2040995a…). Seven bounded JSON files suffice. The source receipt independently binds each original final frame and audio duration; waveform/text fields are not reprocessed. Matched selects all16 final4f cells; resident uses each of four trials' four `per_request` primary records and original request origin. All archived actual offer/D/C/EOS rows remain; no global resident re-origin is introduced. Original a13 quantile/finite code and its common helper are byte-vendored with provenance.

`make_config.py --matched-dir ... --resident-dir ... --source-receipt ... --out NEW_CONFIG.json --raw-out NEW_8TB_OUTPUT [--render]` only writes the frozen input index/config. Grid is fixed in advance at0.5–6s,0.25s increments (23points); C8 remains8s. Rendering is optional because core analysis is pure stdlib. If enabled, Root records matplotlib/Python environment and later visually inspects actual exported PDF pages.

Formal prelaunch contains config SHA and analysis CURRENT/noarg receipt path/SHA. Entry: `analyze_sensitivity.py --config ... --manifest ... --prelaunch ...`. It verifies complete independent source and input bytes, writes the actual run/environment records, then analyzes. Original unweighted linear P99, all offered/partial EOS, per-request origins and D2/C8 positive controls are hard gates: matched0/8→6/8, resident0/8→7/8, credits30→65.821625 and31→64.118875s per66.33975s arm. It never generates a “new pass count” under relaxed thresholds.

Primary Q(tau) numerator is sum of original audio-duration weights satisfying actual D<=tau and C<=8. **Denominator is all offered audio**, including missing D/C and C8 misses. Each source first combines its two timing repeats; paired source gains are reported for four speakers per bank. The matched/resident banks reuse the same four speakers and are never pooled into eight independent sources. No frontier, transition, repeat or grid point is treated as an independent acoustic sample.

Outputs: fixed-grid bank/source curves and source paired differences; original D2 checks; per-repeat D2 pairs; event-exact CDF over all observed finite D values plus anchors0/6; missing/C8-ineligible mass and finite-deadline limits separately. Full CDF never truncates or renormalizes failed/missing mass. Envelopes are descriptive min/max across four source curves, not CI or simultaneous significance. Direction/crossover/negative source gain is a scientific result, never a run gate.

Optional plots use editableSVG, font-embeddedPDF and350dpiPNG at7.125in width,8.5pt minimum labels. Exact step curves are shown for matched and resident; main horizon0.5–6 is predeclared, full-range companion preserves all finite tails. Source paired D2 plot keeps two-repeat ranges and marks them as ranges, not CI. Rendering does not create new measurements.

Formal controls: `python -B -m unittest -v test_sensitivity_controls` (nine distinct controls); Root executes only after clean freeze/preflight. No controls or scripts were run in development. This main adapter intentionally accepts only the old four-source archives. A future twelve-source adapter can byte-reuse `credit`, `validate_primary` and the fixed grid, with a separately frozen schema/count gate; do not change these old-bank positive controls to fit new data.
