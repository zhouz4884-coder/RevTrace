# Independent 16-cell confirmation recount

Pure standard-library CPU analysis of collected immutable bdfa service data.
It recounts all offered D2/C8 metrics including missing observations and EOS,
checks complete original inputs/outputs/C/IDs, eight source/repeat pairs and
GPU role counterbalance, and separates worker-owned from model-path-active
promotions. Direct-start C-entry abandonment proofs are checked against actual
Canonical states. Negative cells and differences are retained.

Source/config/environment/run record, complete input hashes, CPU logs,
all cell results, all eight paired rows, summary and gate are saved separately.
The source is committed and frozen before actual result analysis. No model,
runtime package, dataset download, new source, remote IO or GPU call exists.
