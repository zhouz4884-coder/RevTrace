# 持续合法覆盖与完整协议成本补强

日期：2026-11-02（Asia/Hong_Kong）。用户授权：完成历史合法视图持续覆盖分析、当前完整协议成本实验、选择性修订DSN正文并同步GitHub，不中途请求偏好确认。

研究问题：

1. 已发布且仍有权限的历史完整视图，能否补回当前view-only保留策略留下的持续合法覆盖？按原始实际Consumer时钟，区分已显示覆盖恢复、新root下首次合法与当前view延续；包含EOS，不重复计首次信用。
2. 当前完整协议在真实完整对象、实际Consumer与同步WAL上的CPU、wall和等待成本分别是多少？原C/U模型执行与协议CPU分开；观测开关开销另列，不把instrumentation税当协议净成本。

执行顺序：先复核源身份、环境和原数据，再冻结独立源/配置/环境及原盘路径；运行正式CPU分析与必要真实服务控制；独立复核后才决定论文主张。失败、语义不成立与实现错误分别保留。

原始数据、模型、环境、缓存及大结果保留在指定8TB盘。此目录只归档有界源、manifest、配置、输入索引、统计、判定、图表和论文交付记录。历史GPU原始轨迹的离线反事实分析不会被写成新的部署测量。
